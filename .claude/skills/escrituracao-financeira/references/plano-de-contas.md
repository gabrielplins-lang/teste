# Plano de contas enxuto para MEI / microempresa

Base: modelo da ITG 1000 (CFC, 2022) e prática internacional para microentidades (25–40
contas). Para MEI em regime de caixa, use só as categorias de Receita/Despesa/PL na
planilha; o resto entra quando houver contabilidade completa.
